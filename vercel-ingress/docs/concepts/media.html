Media¶

Brama routes three generation shapes that are not text: an image, a video and a voice. They are reached the way every model here is reached — through an alias or a canonical provider/model route, over the same client identity, the same bounded attempt and the same refusal envelope as a chat completion.

The three shapes¶

EndpointAliasAnswer
POST /v1/images/generationsimage-modelThe provider's image document: data[] carrying b64_json or url, with model rewritten to the route the caller named.
POST /v1/videosvideo-modelA job, not a render: an id and a status. The clip finishes minutes later.
GET /v1/videos/{id}?model=…video-modelThat job as the provider reports it now.
POST /v1/audio/speechvoice-modelEncoded audio bytes, with the provider's own Content-Type. This is the one endpoint that answers no JSON.

Why a status read names a model¶

Brama holds no job state. A video identifier belongs to the provider that issued it, so the caller keeps the identifier and names the same model it started the job with; a gateway that guessed the vendor would eventually ask the wrong one, and a gateway that stored the job would become a second source of truth about somebody else's queue. A status read with no model is refused:

400 {"error":{"code":"invalid_request",
     "message":"a video status read names the model that started the job: GET /v1/videos/{id}?model=…"}}

Who pays¶

The deployment does, through its own provider capability. No subscription in the pool carries an image, video or voice quota, so there is nothing for best to delegate to: a media alias whose route is best fails the shape check at startup and at PUT /v1/admin/routes. Media is the deployment's spend and appears on the deployment's bill.

Which providers¶

A provider serves a media shape only where its vendor documents that exact OpenAI-shaped endpoint. Everything else is declared with an empty path and refused by name, rather than sent a request its server has no route for.

Naming a model¶

Either the deployment's media alias or a canonical route. Two checks stand between a name and a bill:

  • The provider must serve the shape. anthropic/claude-sonnet-4-6 on the image endpoint is refused with `anthropic/claude-sonnet-4-6` cannot generate images: name `image-model` or a provider/model route whose provider does.
  • The model must be that kind. OpenAI declares an image path, so openai/gpt-4o-mini passes the first check and fails the second: `openai/gpt-4o-mini` is a text model: name `image-model` or a provider/model route the catalogue lists as image. The catalogue already says what each model produces, so the kind decides before a credential is redeemed. A route no public catalogue carries is allowed through — a provider serves models no list knows, and refusing those would make the catalogue's blind spots into Brama's.

A media alias named on a chat endpoint is refused by name, exactly as a decision alias is: `image-model` is a media alias: it generates on POST /v1/images/generations or POST /v1/videos, not chat completions.

Declaring the aliases¶

The three media aliases are known by name and required of nobody: a deployment that generates no media declares no route for them and changes no policy to take the release. Unrouted, each reports no_route with the command that repairs it, and a request naming one answers 503 with that same sentence.

$ brama routes set image-model openai/gpt-image-1
$ brama routes set video-model openai/sora-2
$ brama routes set voice-model openai/gpt-4o-mini-tts

Spoken audio24 MiBprovider_failure: spoken audio exceeds the accepted size

Every one of these is decided before a provider is contacted, because a render is billed whether or not the caller meant it.

Not to be confused with¶

  • A vision model. A chat model that reads an image answers on POST /v1/chat/completions and is selected by the any-vision-capable selector. Media is about what a model produces.
  • Image Video Router. That internal service executes caller-built ComfyUI workflows for Content Platform. Brama routes the vendor-hosted media models behind one authenticated gateway, with client identity, catalogue and refusal contract; it builds no workflow graphs.

See category for how the catalogue says what a model produces, brama image, brama video and brama speak for the shell surface.
