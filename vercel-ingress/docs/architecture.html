Brama architecture

Architecture¶

Brama is one Rust process (axum) serving one HTTP listener. Its entire job is to turn an authenticated, alias-shaped model request into one provider HTTP call, paying with a credential it held for exactly that call. An alias resolves to exactly one route; when that route refuses the call, the refusal is what the caller receives.

The architecture material is split across two pages, both linked below: one for the ownership split and the trust boundaries, one for the runtime path a request takes and the state the process keeps.
