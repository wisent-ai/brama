Together together¶

A protocol adapter (provider) reached as together/<model>, speaking openai-chat. It is a direct provider: requests spend through the deployment's own capability credential. The descriptor says what the gateway can speak; a catalog entry never unlocks a credential or manufactures availability.

Endpoints and auth¶

Base URLhttps://api.together.xyz
Trusted hostapi.together.xyz
Chat endpointhttps://api.together.xyz/v1/chat/completions
Model discoveryhttps://api.together.xyz/v1/models
Wire protocolopenai-chat
Auth headerAuthorization: Bearer <credential>
Base URL overrideBRAMA_PROVIDER_TOGETHER_BASE_URL

Provider clients require approved HTTPS hosts, disable redirects, and bypass ambient proxies. The override is validated with the exact refusals listed in provider; a non-loopback override outside the trusted host above is refused as host <host> is not trusted.

Models¶

No pinned rows: the catalog is discovered live from the provider's own models endpoint, bounded at 20 seconds per discovery. Public metadata comes from models.dev and is advisory only.

Credential¶

An API key redeemed at final use through the deployment's capability; it has no refresh path and no invented expiry. No plan-usage report is published — the absence is recorded as the provider's own answer, never as a zero (subscription).
