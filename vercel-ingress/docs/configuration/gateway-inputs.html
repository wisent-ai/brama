Brama configuration reference

Gateway inputs¶

These are the variables the brama serve process itself reads. In a managed installation the launcher assembles the security-bearing ones before exec; see Launcher inputs. A missing, malformed, duplicate, or contradictory value ends startup with a refusal that names the variable. The route registry file has its own page: Route registry.

Alias policy and the route registry are separate inputs with separate jobs. BRAMA_MODEL_ALIASES declares which aliases this installation is required to serve; the registry says which single destination each alias resolves to. A declared alias with no destination is a real state, no_route, and a completion naming it answers 503 alias_unserviceable with details.state and details.route rather than being routed somewhere else. See Alias and Errors.

Sign-in pacing and freshness¶

Plan readings stay current until the window they describe resets, and a credential is refreshed once its stated expiry has passed; neither has a configurable window.

VariableDefaultMeaning
BRAMA_CREDENTIAL_SIGN_IN_COOLDOWN_SECSunset: no cooldown; a failed sign-in is not repeated until the account or Weles revision changes, and the host's brama maintain schedule paces the restwhole seconds the gateway waits before driving a second sign-in for the same stored credential; a value that is not a whole number stops new sign-ins and the log says BRAMA_CREDENTIAL_SIGN_IN_COOLDOWN_SECS must be a whole number of seconds; it is "<value>"
BRAMA_SUBSCRIPTION_LISTING_AGE_SECONDSunset: every caller reads the vault's pool listing, except a caller queued behind a listing already in flight, which takes that listing when it landswhole seconds a successful pool listing is served before the vault is read again. Whatever the age, one listing runs at a time and the callers waiting on it share its answer, so a burst of requests costs one vault read
BRAMA_MODEL_DISCOVERY_AGE_SECONDSunset: every catalog call discovers a credential's models, except a caller queued behind a discovery already in flight for that credential, which takes its answer when it landswhole seconds a credential's discovered models are served before discovery runs again. Whatever the age, one discovery runs per credential at a time and the callers waiting on it share its answer. A member the ledger already refuses — a grant awaiting a sign-in, a retired member, a recorded block — is never discovered: the request path refuses it from the ledger before any vault child or provider is asked
BRAMA_MODEL_DISCOVERY_FAILURE_AGE_SECONDSunset: a refused discovery is tried again on the next call, except by a caller that was waiting while it was refused, which takes that refusalwhole seconds a discovery refusal is answered from memory, with its class, instead of asking the provider again
BRAMA_VAULT_CHILD_RESIDENT_CEILING_BYTES, BRAMA_VAULT_CHILD_FOOTPRINT_CHECK_SECONDSunset: a vault child runs until it endsresident bytes past which a vault command is ended, and how often its footprint is read; the ceiling without the cadence refuses the command by naming the missing variable. The log names every vault child's operation and pid when it starts and when it ends.

The gateway keeps no timer: usage reports, token refreshes and the readiness reading are each taken by one brama maintain pass, which the host's Stado schedule runs. Usage reports and token refreshes are free, and the only quota-spending check is the explicit admin probe route. Signing an account in is not configurable and not an operator action: when a provider refuses a grant, or the stored document is not a credential at all, the gateway asks Weles to sign that account in. Weles drives the browser on its own host; nothing opens one here. BRAMA_CREDENTIAL_SIGN_IN_COOLDOWN_SECS sets how often that may happen for one credential and does not turn it off. A sign-in runs until Weles reports how it ended.

These ages govern how fresh a reading is, not how long a request may run: a completion and a sign-in each run until the provider or Weles answers, and a failure is reported with the error it ended on. A value that is not a whole number is reported by its variable's name; a stored reading is never served under an age nobody declared.

BRAMA_CATALOG_REVISIONbrama-v1revision string reported by /v1/models

STADO_INTEGRATION_API_URL, BRAMA_STADO_INTEGRATION_TOKENunsetoptional remote Stado transport for brama onboard

The catalog describes models; it does not decide routing. An alias is served only through its registered destination, and a model present in the catalog but absent from the registry has no route.

Build identity is baked at compile time from BRAMA_SOURCE_REVISION, BRAMA_BUILD_PLATFORM, and BRAMA_BUILD_TIMESTAMP, and reported by brama version, /health, /readyz, and /stats.
