Brama configuration reference

Gateway inputs¶

These are the variables the brama serve process itself reads. In a managed installation the launcher assembles the security-bearing ones before exec; see Launcher inputs. A missing, malformed, duplicate, or contradictory value ends startup with a refusal that names the variable. The route registry file has its own page: Route registry.

BRAMA_MODEL_ROUTER_CLIENT_IDENTITIESunsetJSON array of {client_id, token, agent_id?, allowed_models?}. Absent means "ask the authority", not "misconfigured": a bearer that is not in this table is resolved against Skarbiec, and Skarbiec's answer is the answer

Alias policy and the route registry are separate inputs with separate jobs. BRAMA_MODEL_ALIASES declares which aliases this installation is required to serve; the registry says which single destination each alias resolves to. A declared alias with no destination is a real state, no_route, and a completion naming it answers 503 alias_unserviceable with details.state and details.route rather than being routed somewhere else. See Alias and Errors.

Timers and freshness¶

VariableDefaultMeaning
BRAMA_PLAN_USAGE_TTL_SECS300freshness window per subscription's provider usage report; also when a reading turns stale
BRAMA_PLAN_USAGE_SWEEP_SECS60how often aged-out readings are looked for; 0 disables the sweep
BRAMA_PLAN_USAGE_RETENTION_SECS86400when a stale reading stops being served
BRAMA_CREDENTIAL_REFRESH_INTERVAL_SECS60refresh-ahead sweep interval; 0 disables it
BRAMA_CREDENTIAL_REFRESH_SKEW_SECS300refresh credentials expiring within this window
BRAMA_CREDENTIAL_AUTOMATIC_SIGN_INunset (off)only 1 enables automatic Weles browser sign-in after a credential refusal or a missing account mapping; OAuth token renewal remains enabled independently

With these defaults no timer performs a quota-consuming request: usage reports and token refreshes are free, and the only quota-spending check is the explicit admin probe route. No default timer opens a browser; signing in requires the separate CLI or Desktop action unless automatic Weles renewal was explicitly enabled.

These windows govern how fresh a reading is, not how long a request may run. A completion carries the deadline of its one attempt against its one route; that deadline is not multiplied by anything.

Catalog and providers¶

VariableDefaultMeaning
BRAMA_MODEL_CATALOG_URLhttps://models.dev/api.jsonpublic metadata origin
BRAMA_MODEL_CATALOG_TTL_SECONDS900in-memory catalog TTL
BRAMA_MODEL_CATALOG_PATHunsetread the catalog from a local file instead of the origin
BRAMA_MODEL_CATALOG_CACHE/tmp/brama-models-dev-cache.jsonreplaceable on-disk cache
BRAMA_CATALOG_REVISIONbrama-v1revision string reported by /v1/models
BRAMA_PROVIDER_<PROVIDER>_BASE_URLbuilt-inper-provider base override; an exact trusted HTTPS host or an explicit loopback address only
STADO_INTEGRATION_API_URL, BRAMA_STADO_INTEGRATION_TOKENunsetoptional remote Stado transport for brama onboard

The catalog describes models; it does not decide routing. An alias is served only through its registered destination, and a model present in the catalog but absent from the registry has no route.

Build identity is baked at compile time from BRAMA_SOURCE_REVISION, BRAMA_BUILD_PLATFORM, and BRAMA_BUILD_TIMESTAMP, and reported by brama version, /health, /readyz, and /stats.
