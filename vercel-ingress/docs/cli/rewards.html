Brama CLI command reference

brama rewards¶

This gateway's side of Wisent's contribution ledger, which lives in compute.wisent.com. The gateway reports the days a donated subscription served the pool, and serves an alias it gates beyond a credential's model scope only to a caller the ledger says holds the entitlement to it. A gateway that declares no ledger reports nothing and gates nothing.

Invocation¶

brama rewards status [--alias <ALIAS> [--agent-id <ID>]] [--json]
InputRequired/defaultMeaning
--alias <ALIAS>optionalThe alias to report on: whether BRAMA_ENTITLEMENT_GATED_ALIASES gates it, and with --agent-id the ledger's answer about the entitlement.
--agent-id <ID>with --aliasThe identity whose entitlement to ask the ledger about: an agent id, or a client id that signs as no agent.
--jsonoptional; offPrint one object instead of key: value lines.

What it reads¶

BRAMA_CONTRIBUTION_LEDGER_URL names the ledger; the bearer the gateway presents as the reporter brama is read through the Skarbiec route for the contribution-ledger resource. Brama links no one: a signed-in Wisent user links their account on the Rewards page of compute.wisent.com (Link my Brama donations), which reads the account from that sign-in, and a workload's credential, presented by every process that holds it, links nothing. Brama Desktop's Rewards screen does what status does through POST /v1/rewards/status with {"alias", "agent_id"}, which only the console may ask.

Output and state¶

$ brama rewards status --alias wisent/sol --agent-id example-agent
ledger: https://compute.example.test
alias: wisent/sol
gated: true
agent_id: example-agent
entitlement: {"granted":false,"message":"the account holds no current model.access entitlement for wisent/sol","reason":"entitlement_absent"}

Exit code is 0 when the report was given.

Refusals¶

SentenceMeaning
this gateway declares no contribution ledger (BRAMA_CONTRIBUTION_LEDGER_URL)Nothing to ask; declare the ledger's origin.
the contribution ledger did not answer: its bearer could not be read: …The Skarbiec route for contribution-ledger is missing or refused.

Every refusal exits 1 and prints on standard error. See the CLI tree.
