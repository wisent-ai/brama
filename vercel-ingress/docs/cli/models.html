Brama CLI command reference

brama models¶

Every model this gateway can name, with the three facets category defines: what it produces, whether its weights are published, and which declared categories it carries. It reads the public catalogue and the operator's route registry directly, so it answers before a gateway is running and needs no bearer.

Invocation¶

brama models [--kind <KIND>] [--weights <WEIGHTS>] [--category <NAME>] [--provider <ID>] [--search <TEXT>] [--limit <N>] [--json]
InputRequired/defaultMeaning
--kind <KIND>optionaltext, image, video or audio.
--weights <WEIGHTS>optionalopen or closed. A model whose source stated neither matches neither.
--category <NAME>optionalA category the operator declared, such as uncensored.
--provider <ID>optionalOne provider identifier.
--search <TEXT>optionalText contained in the route id or the published name.
--limit <N>optional; fiftyHow many matches to print. Zero prints every one.
--jsonoptional; offPrint the listing as a document instead of a table.

Output and state¶

Real runs against the live catalogue:

$ brama models --kind image --limit 3
ROUTE                                                KIND   WEIGHTS  CATEGORIES       PROVIDER
302ai/gemini-3.1-flash-image-preview                 image  closed   -                302ai
abacus/gemini-2.5-flash-image                        image  closed   -                abacus
abacus/gemini-3-pro-image                            image  closed   -                abacus
3 of 188 matching models, catalogue models-dev-2026-09-21-222-7922

$ brama models --category uncensored --limit 3
ROUTE                                                KIND   WEIGHTS  CATEGORIES       PROVIDER
abliteration-ai/abliterated-model                    text   open     uncensored       abliteration-ai
abliteration-ai/abliterated-model-large              text   closed   uncensored       abliteration-ai
nano-gpt/TEE/gemma-4-26b-a4b-uncensored              text   open     uncensored       nano-gpt
3 of 24 matching models, catalogue models-dev-2026-09-21-222-7922

The WEIGHTS column reads unknown where the catalogue stated nothing, which is a different answer from closed. With --json each row carries route, name, provider, kind, openWeights, inputModalities, outputModalities and categories, beside the catalogue revision and how many models matched. The command writes nothing.

Refusals¶

SentenceMeaning
kind must be text, image, video or audioThe same sentence GET /v1/models?kind= answers. A filter the gateway cannot read never answers the whole catalogue.
weights must be open or closedAs above, for the weights facet.
the model catalogue could not be read: <reason>Neither models.dev nor the on-disk copy answered.

Every refusal exits 1 and prints on standard error.

See category, brama categories, or the CLI tree.
