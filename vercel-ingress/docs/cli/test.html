Brama CLI command reference

brama test¶

Run one test inference through the named agent’s subscription credential, not the deployment’s direct provider capability.

Invocation¶

brama test [-m <ROUTE>|--model <ROUTE>] [--agent-id <ID>] --allow-provider-cost
InputRequired/defaultMeaning
-m, --model <ROUTE>optional; openai/defaultCanonical route to test.
--agent-id <ID>optional; wisent-appAgent whose provider credential is used.
--allow-provider-costrequired by runtime; offAcknowledge the billable provider request.

Output and state¶

Success prints Model:, Response:, input/output token counts, latency, and cost, then exits 0. It performs one billable request and may update normal subscription usage state; it does not print credentials.

Refusals¶

refusing billable inference without explicit --allow-provider-cost

That refusal exits 1 before a request. A dispatch failure prints Error: <dispatch reason> (for example, Error: no active 'openai' credential for agent) and exits 1.
