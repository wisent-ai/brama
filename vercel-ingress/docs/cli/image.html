Brama CLI command reference

brama image¶

Render one image from a shell through the same route, the same Skarbiec credential redemption and the same refusals POST /v1/images/generations uses. It exists for the two moments the HTTP surface cannot cover: establishing that a media route answers at all before a gateway runs, and diagnosing one that stopped.

Invocation¶

brama image --prompt <TEXT> [--model <ALIAS|ROUTE>] [--size <SIZE>] [--n <COUNT>] [--quality <QUALITY>] [--output <FILE>] [--json] --allow-provider-cost
InputRequired/defaultMeaning
--prompt <TEXT>requiredWhat to render.
--model <ALIAS|ROUTE>optional; image-modelThe media alias, or a canonical provider/model route the catalogue lists as an image model.
--size <SIZE>optionalThe provider's own size string, such as 1024x1024.
--n <COUNT>optionalHow many images. The endpoint accepts between one and ten.
--quality <QUALITY>optionalThe provider's own quality string.
--output <FILE>optionalDecode the returned bytes and write them there. Several images are numbered beside that name.
--jsonoptional; offPrint the provider's document instead of lines.
--allow-provider-costrequired to send anythingAcknowledge that this performs a billable provider request.

Output and state¶

A successful run prints the alias, the route it resolved to, how many images came back, and for each one either the URL the provider returned or the path and byte count this command wrote. Without --output the encoded length is reported rather than dumped into a terminal.

A refused run prints the provider's own sentence and exits non-zero. This is a real one, against image-model routed to openai/gpt-image-1 on a deployment whose OpenAI account has no credit:

$ brama image --prompt "a plain red square on a white background" --size 1024x1024 --output square.png --allow-provider-cost
credential obtained at final use event="credential_obtained" resource="provider:openai" path="read-grant"
provider_rate_limited: You have no credits remaining. Add credits to continue using the API at https://platform.openai.com/settings/organization/billing/.

The command reads the route registry and writes only the file it was asked for.

Refusals¶

SentenceMeaning
refusing a billable image generation without explicit --allow-provider-costNothing was sent. Nothing is spent by running this command by accident.
alias `image-model` is a media alias this gateway knows but no route is declared for it; declare one with `brama routes set image-model <provider/model>` or `PUT /v1/admin/routes`The alias has no route here.
invalid_request: route `anthropic/claude-sonnet-4-6` does not generate imagesThe named route's provider serves no image endpoint.
provider_rate_limited: <the provider's own sentence>The route was reached and refused — no credits, a rate limit, a rejected key.
the provider's image is not base64: <reason>The answer arrived but its bytes could not be decoded, so no file was written.

Every refusal exits 1 and prints on standard error.
