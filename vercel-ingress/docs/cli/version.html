Brama CLI command reference

brama version¶

Print Brama product and build identity as one secret-free JSON object.

Invocation¶

brama version

This command accepts no inputs or options.

Output and state¶

{"product":"brama","version":"0.2.41","source_revision":"development","platform":"development-host","built_at":"not-recorded"}

The fields are product, package version, compile-time source_revision, platform, and built_at. Development builds use the placeholders shown. The command writes no state, reads no credential, and exits 0 after printing.

Refusals¶

There is no product-level refusal. Clap rejects unsupported operands or options before this command runs.
