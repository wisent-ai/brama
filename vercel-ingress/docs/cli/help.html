Brama CLI command reference

brama help¶

Print help for Brama or for one nested command path.

Invocation¶

brama help [COMMAND]...

The optional command path may name a top-level command and, for grouped commands, its leaf subcommand, such as brama help subscription sign-in.

Output and state¶

It prints the selected command’s purpose, usage, options, and subcommands. It performs no network request, reads no credential, writes no state, and incurs no cost.

Refusals¶

Clap refuses an unknown command path before any product handler runs and prints the closest usage context. There is no product-level refusal.
