Brama CLI command reference

brama diagnose¶

On the gateway's own host, explain why Brama is or is not serving. It opens every file the launcher reads, in the order the launcher reads them, and prints each beside what it has to agree with.

Invocation¶

brama diagnose [--json]
InputRequired/defaultMeaning
--jsonoptional; offPrint the same lines once as {"sections": [{"title", "lines"}]}, one section per heading, instead of printing them as they are found.

What it reads¶

Sections, in order:

  • units that start Brama — ~/.stado/services/brama/current, where it points, and the release state ~/.stado/release-state/brama.json records as serving.
  • installed generations — every installed generation, the files it is missing, whether its entitlements router answers grant capability, and whether its trust registry pins that exact binary.
  • service env — ~/.config/brama/service.env; a value is shown only when it is an existing path, so no secret is printed.
  • policy grants against authority routes — the provider grants in the generation's policy.json against the authority-owned routes table.
  • alias routes against routed provider grants — each alias route against the providers policy and routes both allow.
  • reachability — the loopback port service.env names (or a line saying it names none), the address the gateway announced when it bound, and every origin tailscale serve status publishes, each with the status it answered.
  • current boot attempt — the whole unit log (~/.stado/logs/<unit>.log) from the last line brama launcher: boot attempt of <installation>; a log written by a launcher that predates that line is shown whole under the unit's log (no boot attempt marker in it).

Output and state¶

Read-only: it writes nothing and contacts no provider. A file it cannot read is reported as a line in its section rather than ending the report, so one missing file does not hide the others. It exits 0 once the report is printed; the report, not the exit status, says whether the gateway can serve. To see whether each alias actually answers, run brama probe.

Refusals¶

An unknown argument is refused by the parser with exit 2. There is no other refusal.
