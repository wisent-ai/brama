Brama CLI command reference

brama workload deregister¶

Withdraw what brama workload register granted: revoke the vault grant of every agent this installation's workload names.

Invocation¶

brama workload deregister [--json]

What it reads and writes¶

It finds the router, vault and registry.json exactly as register does, and runs skarbiec-entitlements-router grant revoke for each agent the first workload names. Revoking a grant the vault no longer holds changes nothing, so a rerun is harmless. After it, the broker refuses every capability for those agents until register runs again.

Output¶

registry and the revoked agents as key: value lines, or one document with --json. Exit 0 means every grant was revoked.

Refusals¶

Each exits 1; on a router refusal the agents before it are already revoked:

  • ENTITLEMENTS_ROUTER_BIN and SKARBIEC_VAULT_FILE must be named by the running installation, environment, or service env
  • no workload registry at <path>
  • <registry> names no agent whose grant could be revoked
  • grant revoke for <agent> could not run: <error>; grant revoke refused <agent>: <router's own answer>
