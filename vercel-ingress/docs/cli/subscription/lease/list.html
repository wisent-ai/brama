Brama CLI command reference

brama subscription lease list¶

Every live lease the gateway holds, and how many sessions each subscription carries, read from the gateway's register; the same counts brama subscription list shows as each member's live_sessions.

Invocation¶

brama subscription lease list (--gateway <ORIGIN> | --gateway-consumer <NAME>) [--bearer-role <ROLE>] [--json]
InputRequired/defaultMeaning
--gateway <ORIGIN> or --gateway-consumer <NAME>one requiredThe gateway that holds the pool (GET /v1/subscription-pool/leases). The console bearer is read from stdin, or from the vault item playing --bearer-role.
--jsonoptional; offPrint {limit, leases: [lease...], counts: {subscription_id: n}} instead of lines.

Output and state¶

limit per subscription: <n> (or none stated, so no lease is given), one line per live lease, then <subscription> carries <n> per subscription with a lease. Nothing is written.

Refusals¶

A gateway refusal exits 1 and prints its error document: 503 with the cause when the register cannot be read. Without a gateway: a lease lives on the gateway that holds the pool: name --gateway or --gateway-consumer.

The real test is tests/subscriptions/leases.sh. See the command group or the CLI tree.
