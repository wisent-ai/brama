Brama CLI command reference

brama detect¶

Detect local hardware capabilities and select the model and backend Brama recommends for that host.

Invocation¶

brama detect

This command accepts no inputs or options.

Output and state¶

It prints GPU type and name, VRAM, RAM, CPU core count, CUDA and Metal availability, then Recommended model: and Recommended backend:. It performs no network request, reads no credential, writes no state, incurs no provider cost, and exits 0.

Refusals¶

There is no product-level refusal. Clap rejects unsupported operands or options before detection runs.
