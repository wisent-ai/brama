Brama CLI command reference

brama subscription¶

Enter the command group that acts on one provider’s subscription credentials.

Invocation¶

brama subscription <COMMAND>

A subcommand is required. This group has no options and performs no mutation by itself.

Commands¶

  • brama subscription refresh <PROVIDER> --reason <REASON> [--json] — refresh one provider’s grants now.
  • brama subscription sign-in <PROVIDER> --reason <REASON> [--login-item <LOGIN_ITEM>] [--login-timeout-ms <MILLISECONDS>] [--json] — drive an exact Weles account sign-in and prove it with a refresh.

Output, state, and refusals¶

The group command itself produces only help or parser errors and changes no state. Omitting <COMMAND> or naming anything other than refresh or sign-in is refused by Clap before a handler runs; use brama subscription --help to print the accepted tree.
